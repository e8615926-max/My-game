# World Simulator — симулятор бога

Оригинальная 2D-песочница в жанре «симулятор бога»: процедурные миры, четыре народа с собственным ИИ, королевства, дипломатия, войны, торговля и божественные силы. Чистый HTML5 Canvas + JavaScript, без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере (телефон или компьютер) либо разместите папку на любом статическом хостинге (GitHub Pages, Vercel).

## Управление

- **Телефон:** один палец — двигать карту или рисовать выбранной силой; два пальца — масштаб и перемещение; нажатие в режиме «Осмотр» — выбрать существо или поселение.
- **Компьютер:** колесо — масштаб; правая кнопка или WASD/стрелки — перемещение; пробел — пауза; 1–3 — скорость; Esc — режим осмотра.

## Структура

| Файл | Назначение |
| --- | --- |
| `js/core.js` | константы, шум, определения рельефа, существ, построек, имена |
| `js/world.js` | состояние мира, генерация, регионы, поиск пути A*, пространственная сетка |
| `js/units.js` | существа: движение, ИИ работников, воинов, животных, чудовищ |
| `js/civ.js` | поселения, строительство, королевства, дипломатия, войны, торговля |
| `js/nature.js` | огонь, лава, погода, бедствия, случайные события, главный тик |
| `js/powers.js` | божественные силы |
| `js/save.js` | сохранение и загрузка (слоты, автосохранение, файл) |
| `js/render.js` | пиксель-арт рельефа, спрайты, камера, эффекты, мини-карта |
| `js/ui.js` | интерфейс, сенсорный ввод, панели, игровой цикл |
| `js/lang.js` | локализация (русский / английский) |
